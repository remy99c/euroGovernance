# Dependency security risk register

Last reviewed: 2026-08-21

The release gate runs `npm run security:audit` and fails on high or critical
production dependency advisories. Dependency versions are exact for the web,
Firebase runtime, and deployment CLI packages.

## TEMP-DEP-001 — `uuid` through Firebase Admin Storage

- Severity: moderate
- Advisory: `GHSA-w5hq-g745-h8pq`
- Dependency path: `firebase-admin@14.3.0` → optional
  `@google-cloud/storage@7.22.0` → `teeny-request@9.0.0` → `uuid@9.0.1`
- Exposure: the vulnerable functions are UUID v3/v5/v6 when a caller supplies a
  destination buffer. euroGovernance does not call those UUID functions and does
  not accept a client-provided UUID buffer. Evidence object identifiers are
  generated by Firestore or cryptographic random bytes.
- Treatment: temporarily accepted as an upstream transitive risk. Do not
  downgrade Firebase Admin: Firebase Functions 7 requires Firebase Admin 11–14,
  and the audit tool's proposed downgrade is incompatible. Do not force a
  semver-incompatible transitive override into the production Storage SDK.
- Compensating controls: evidence Storage operations remain disabled until the
  server-verified upload pipeline is implemented; CI rejects any high/critical
  production advisory; exact lockfile is committed.
- Exit condition: upgrade when Firebase Admin adopts a non-vulnerable Storage
  dependency, then remove this entry after the complete build/emulator gate.
- Owner: platform security
- Review cadence: every dependency milestone and at least monthly

## Development tooling advisories

Moderate advisories in Firebase CLI telemetry dependencies are development/CI
only and are excluded from the production audit. The CLI is exact-pinned and is
not shipped in Hosting or Cloud Functions artifacts. Revisit them on every CLI
upgrade; high or critical advisories remain release-blocking.
